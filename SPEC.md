## Roles
1. ADMIN
2. MODERATOR
3. APPLICANT

# Authentication

## Admin
Predetermined username and password.
Admin is able to do everything

## Moderator
Predetermined username and password or can be created by admin.
Moderator have all access except other creating a new moderator or admin.

## Applicant
Applicants need to enter the phone number first and the system will check if the user exists or not in the database. If not the system will send the 6 digit OTP to the number and the user can login with that OTP then the system will prompt them to create a new password. If the user exists the system prompts to enter the password. After the authentication the user can access the main endpoints

But currently the SMS service is not ready so just use the mock service for OTP [for only local development] print the code to the console

## Application flow
Successfully logged in applicant has to be able to create an application.
Then the application will go through the review process. During this process the application will be reviewed by the moderators. If the application is accepted the applicant can proceed to the exam.
If the application is rejected the applicant will be notified and the application will be closed.

## Exam Flow 
The exam questions will be generated by the system based on the applicant's chosen major and subject.
The exam will be conducted online and the duration of the exam will be calculated based on the subject table in database.
Only final score needs to be shown to the user after exam, No need questions and answers results.
The final score will be maximum (189), minimum (56) unofficially.
After the exam user needs to be able to download the contract file if accepted.
Contracts are generated in the system as a pdf format.
If the final score is more than 56.4 the tuition fee scale will be 1.0 otherwise it will be 1.5 untill 40. other wise will be cancelled
